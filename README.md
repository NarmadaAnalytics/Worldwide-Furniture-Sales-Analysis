# Worldwide Furniture Sales Analytics | Excel Dashboard

An Excel-based analytics project focused on analyzing worldwide furniture sales, profitability, customer performance, and outstanding receivables using PivotTables, slicers, and an interactive dashboard.

## Business Questions

This project was built to answer the following questions:

1. Which regions and countries generate the highest sales?
2. Which customers contribute the most revenue?
3. How do sales vary across customer segments and product categories?
4. Which shipping modes are used most frequently?
5. What is the distribution of outstanding receivables across aging buckets?
6. How can business users interactively filter and review performance by region, country, customer, and segment?

**Pipeline:** Raw Excel Data → Data Cleaning → PivotTables → Slicers → Interactive Excel Dashboard

## Dataset

The analysis uses two source workbooks:

- `Capstone 2019.xlsx`
- `Capstone 2020.xlsx`

The data includes fields such as customer, region, country, segment, shipping mode, product category, sales, cost, profit, and receivable aging buckets.

## Process

1. Reviewed and cleaned the source data in Excel.
2. Combined and organized the 2019 and 2020 datasets for analysis.
3. Created PivotTables to summarize sales and receivables.
4. Built calculated views for regional, customer, segment, and category analysis.
5. Added slicers for interactive filtering.
6. Designed an Excel dashboard for quick business analysis.

## Excel Dashboard

The dashboard allows users to filter and analyze data by:

- Customer
- Region
- Country
- Segment

It also provides visibility into:

- Total Sales
- Customer and regional performance
- Product categories
- Shipping modes
- Receivable aging buckets
- Transaction-level details

![Worldwide Furniture Excel Dashboard](dashboard.png)

## Key Insights

- Sales are concentrated in a small number of regions and countries.
- Customer and segment filters make it easy to identify high-value accounts.
- Product category and shipping-mode analysis help explain differences in sales performance.
- Receivable aging buckets provide visibility into outstanding amounts and potential collection risks.
- Interactive slicers allow users to move quickly from a worldwide view to specific customers or markets.

## Recommendations

- Prioritize high-value customers and regions for retention and account-growth initiatives.
- Review older receivable aging buckets regularly to reduce collection risk.
- Compare category performance across regions to identify cross-sell opportunities.
- Use the dashboard as a recurring management view for customer, sales, and receivables analysis.
